# Tic-Tac-Toe Game 🎮

![Tic-Tac-Toe Preview](https://github.com/AnkithKA/Tic-Tac-Toe/raw/main/assets/game-preview.png)

A classic Tic-Tac-Toe game built with modern web technologies. Play against a friend or challenge the AI in this timeless game of X's and O's!

## ✨ Features

- **Multiple Game Modes**
  - Player vs Player
  - Player vs AI
  
- **Interactive UI**
  - Clean, responsive design
  - Game state visualization
  - Score tracking

- **Customization Options**
  - Choose your marker (X or O)
  - Select who goes first
  - Toggle sound effects

## 🛠️ Technologies Used

- **HTML5** - Structure
- **CSS3** - Styling and animations
- **JavaScript** - Game logic and interactivity

## 🎯 How to Play

1. Open the game in your web browser
2. Choose a game mode (vs Player or vs AI)
3. Select your marker (X or O)
4. Take turns placing your marker on the 3x3 grid
5. First player to align 3 markers horizontally, vertically, or diagonally wins!
6. If all cells are filled without a winner, the game ends in a draw

## 🚀 Getting Started

### Run Locally

1. Clone the repository
   ```bash
   git clone https://github.com/AnkithKA/Tic-Tac-Toe.git
   ```

2. Navigate to the project directory
   ```bash
   cd Tic-Tac-Toe
   ```

3. Open `index.html` in your preferred web browser
